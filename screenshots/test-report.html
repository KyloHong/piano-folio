总结 · 搜索栏行为对比
场景搜索栏歌词区域核心 state
1. 公共图谱详情隐藏只读isReadOnly=true, isNewChart=false
2. 我的图谱详情隐藏可编辑isReadOnly=false, isNewChart=false
3. 新建图谱显示可编辑isReadOnly=false, isNewChart=true

核心控制逻辑

enterChartView() 函数根据 state.isNewChart 判断是否给 #homeSearchSection 添加 readonly-hidden class:

function enterChartView() {
  const searchSection = document.getElementById("homeSearchSection");
  // 仅新建图谱时显示搜索栏，编辑已有图谱时隐藏
  if (searchSection) {
    searchSection.classList.toggle("readonly-hidden", !state.isNewChart);
  }
}

function openChartEditor() {
  state.isNewChart = true;   // 新建图谱 - 显示搜索栏
  state.isReadOnly = false;  // 新建图谱 - 可编辑
  enterChartView();
}

// renderLyrics 中根据 isReadOnly 条件渲染：
//   isReadOnly=true:  .lyric-char.readonly + 无 onclick + .line-actions 不渲染
//   isReadOnly=false: .lyric-char + 有 onclick（打开和弦面板）

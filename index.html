Music Theory Fundamentals

从认识音名、音级到理解音阶结构，建立学习和弦的乐理基础。系统掌握十二平均律、音程关系与大调小调的核心逻辑。

01音名与十二平均律

什么是音名？

西方音乐使用 C D E F G A B 七个字母命名基本音级，对应简谱的 1 2 3 4 5 6 7。在它们之间还存在 5 个升降音（黑键），总共 12 个音构成一个八度。

相邻两个音（如 C→C#、E→F）之间的距离称为半音，两个半音等于一个全音。

CC#DD#EFF#GG#AA#B

一个八度 = 12 个半音

02音级与简谱数字

大调的音级关系

以 C 大调为例，各音级之间的距离遵循"全全半全全全半"的固定模式。3 到 4、7 到 1 之间是半音，其余相邻音级之间是全音。无论移到哪个调，这个相对关系保持不变。

🎯 写法规范：音名 C# vs 简谱 #1

本站统一：音名升号在后，简谱升号在前
✅ 正确：C# · F#m · #1 · A/C#
❌ 不推荐：#C · #Fm · 1# · A/#C

为什么不一样？ 这是两套独立系统的书写习惯不同：

  • 音名（国际通用）：字母为主、升号为辅 —— C# 读作「C sharp」，升号写在音名后面，和乐谱记谱一致。
  • 简谱（中国体系）：数字为主、升号为辅 —— #1 读作「升 Do」，升号写在数字前面，这是简谱专用写法。

一句话：字母带# → 放后面（C#）；数字带# → 放前面（#1），不要搞反。

对应记忆口诀

C# 对 #1，D# 对 #2，F# 对 #4，G# 对 #5，A# 对 #6。
字母在后数字在前，黑键简谱一一对应。

🎼 和弦名是怎么拼出来的？

和弦名 = 根音（音名格式） + 性质（后缀）
C# + m  = C#m  （C#小三和弦）
F# + m7 = F#m7 （F#小七和弦）
C# + maj7 = C#maj7 （C#大七和弦）
A  / C# = A/C#  （A和弦 / C#低音）

斜杠和弦（Slash Chord）：左边是和弦本体，右边是实际要弹的最低音（低音）。低音也按「升号在后」的音名规则写。

04大调与小调

两种基础调性色彩

大调 (Major)：明亮、开阔、愉悦。主和弦为大三和弦。

小调 (Minor)：柔和、忧郁、深沉。主和弦为小三和弦。

小调的三级音比大调低半音，这是两者最核心的听觉差异。自然小调的音级关系为："全半全全半全全"。

KEY POINT

关系大小调共用相同的调号（升降号），但主音不同。C大调的关系小调是A小调。

Chord Inversions · 和弦转位

转位是和弦演奏的核心技巧。通过改变低音的位置，让和声连接更流畅。斜杠和弦（Slash Chord）是转位的通用记谱写法，同时还能表达非和弦外低音的"经过低音"。

01什么是转位？

换一个音做低音

原位和弦：根音在最低音位置。

转位和弦：三音或五音作为最低音。和弦的构成音不变，只是排列顺序和高低位置改变了。

• 第一转位（六和弦）：三音在最低音

• 第二转位（四六和弦）：五音在最低音

C 和弦的三种形态
原位
C (1, 低音)E (3)G (5)
第一转位
E (3, 低音)G (5)C (1, 升高八度→C5)
第二转位
G (5, 低音)C (1, 升高八度→C5)E (3, 升高八度→E5)
为什么需要转位？

① 保持低音平稳：避免频繁大跳，让连接更流畅。② 适应手型：转位后的音排列更集中，手指更舒适。③ 声部平衡：控制高低音区的分布。

以 C 大三和弦为例，观察转位时各音在键盘上的位置移动。绿色表示当前低音，橙色表示其他和弦音。

04关键区分：斜杠 ≠ 一定是转位

一句话记住

C/G：是斜杠和弦，同时也是转位和弦。斜杠只是一套记谱符号，转位是它的和声本质。

通俗说：所有转位和弦都可以写成斜杠格式（例如 C 第一转位 → C/E，C 第二转位 → C/G，G 第一转位 → G/B…）；但不是所有斜杠和弦都是转位——当斜杠右边的低音不在左边和弦音里时，它就是一条独立的低音旋律线（例如 C/B、Am/G）。

✅ 低音 ∈ 和弦音 → 就是转位

3 5 1

G (低音)C5E5

规律：斜杠右边的音如果能在右手和弦音里找到，那就是一次"把这个音沉到最低"的排列重组——即转位。

❌ 低音 ∉ 和弦音 → 非转位（经过低音）

这是 C/B 这种写法的真相——低音 B 并不是 C 和弦（C E G）的音，它的作用是让低音线变成一条独立的旋律。

Am / G低音 G ↓ 继续下降

卡农、流行歌里最常见的这条 C → C/B → Am → Am/G → F，听感高级完全来自左手那条下行低音。

Arpeggio Patterns · 分解和弦弹法

把和弦音依次弹出来叫"分解和弦"（琶音 / Arpeggio）。钢琴伴奏的灵魂就是分解。从最简单的逐个按音，到复杂的双手交替，下面按难度从 Lv.1 到 Lv.5 渐进学习。

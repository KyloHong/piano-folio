Music Theory Fundamentals

从认识音名、音级到理解音阶结构，建立学习和弦的乐理基础。系统掌握十二平均律、音程关系与大调小调的核心逻辑。

01音名与十二平均律

什么是音名？

西方音乐使用 C D E F G A B 七个字母命名基本音级，对应简谱的 1 2 3 4 5 6 7。在它们之间还存在 5 个升降音（黑键），总共 12 个音构成一个八度。

相邻两个音（如 C→C#、E→F）之间的距离称为半音，两个半音等于一个全音。

C C# D D# E F F# G G# A A# B

一个八度 = 12 个半音

02音级与简谱数字

大调的音级关系

以 C 大调为例，各音级之间的距离遵循"全全半全全全半"的固定模式：

1=C 2=D 3=E 4=F 5=G 6=A 7=B

3 到 4、7 到 1 之间是半音，其余相邻音级之间是全音。无论移到哪个调，这个相对关系保持不变。

03大调与小调

两种基础调性色彩

大调 (Major)：明亮、开阔、愉悦。主和弦为大三和弦。

小调 (Minor)：柔和、忧郁、深沉。主和弦为小三和弦。

小调的三级音比大调低半音，这是两者最核心的听觉差异。自然小调的音级关系为："全半全全半全全"。

C 大调 (C Major)

A 小调 (A Minor, C大调关系小调)
A — B — C — D — E — F — G
☾ 柔和深沉
KEY POINT

关系大小调共用相同的调号（升降号），但主音不同。C大调的关系小调是A小调。

Chord Structure

和弦是三个或以上不同音高按一定音程关系叠置而成的组合。掌握和弦构成原理，就能从「背和弦」进阶到「推和弦」。

01三和弦的基本构成

根音 + 三度 + 五度

最基础的和弦是三和弦，由三个音组成：

• 根音 (Root)：和弦的基础音，决定和弦的"名字"（C和弦根音就是C）。

• 三音 (3rd)：根音上方三度的音，决定和弦是大还是小。

• 五音 (5th)：根音上方五度的音，提供和弦的稳定性。

03七和弦：再加一个三度

在三和弦上叠置第七音

七和弦由 四个音 组成：根音、三音、五音、七音。根据七音的性质（大七度或小七度），形成不同类型的七和弦：

• 大七和弦 (maj7)：三和弦 + 大七度（根音上 11 半音），色彩梦幻、爵士。

• 属七和弦 (7)：三和弦 + 小七度（根音上 10 半音），有强烈的解决倾向。

• 小七和弦 (m7)：小三和弦 + 小七度，忧郁中带流动感。

Chord Inversions

转位是和弦演奏的核心技巧。通过改变低音的位置，让和声连接更流畅，左右手分配更合理。理解转位，才能真正弹好钢琴伴奏。

01什么是转位？

换一个音做低音

原位和弦：根音在最低音位置。

转位和弦：三音或五音作为最低音。和弦的构成音不变，只是排列顺序和高低位置改变了。

三和弦有两种转位：

• 第一转位：三音在最低音（六和弦，低音上方是三度+六度）

• 第二转位：五音在最低音（四六和弦，低音上方是四度+六度）

C 和弦的三种形态
原位
C (1, 低音) E (3) G (5)
第一转位
E (3, 低音) G (5) C (1, 升高八度→C5)
第二转位
G (5, 低音) C (1, 升高八度→C5) E (3, 升高八度→E5)
为什么需要转位？

① 保持低音平稳：避免频繁大跳，让连接更流畅。② 适应手型：转位后的音排列更集中，手指更舒适。③ 声部平衡：控制高低音区的分布，让和声更好听。

02转位在键盘上的变化

以 C 大三和弦为例，观察转位时各音在键盘上的位置移动。绿色表示当前低音，橙色表示其他和弦音。

原位：C — E — G （低音 C） 1 3 5
第一转位：E — G — C5 （低音 E，C 升高八度） 3 5 1
第二转位：G — C5 — E5 （低音 G，C、E 均升高八度） 5 1 3

Interval Reference

音程是两个音之间的距离，是构建和弦的"材料"。熟记下面这张音程表，就能自己推算出任何和弦的组成音。

01完全音程与大/小音程

音程由两个维度描述：度数（包含几个音级，从 1 数起）+ 半音数（实际距离，决定"大/小/增/减"）。

半音数 音程名称 简谱 (C根) 音名示例 (C→) 听感特征
0 纯一度 (Perfect Unison) 1 → 1 C → C 完全一致
1 小二度 (Minor 2nd) 1 → b2 C → Db 极不协和
2 大二度 (Major 2nd) 1 → 2 C → D 轻度紧张
3 小三度 (Minor 3rd) 1 → b3 C → Eb 柔和·小和弦
4 大三度 (Major 3rd) 1 → 3 C → E 明亮·大和弦
5 纯四度 (Perfect 4th) 1 → 4 C → F 稳定·空泛
6 增四度 / 减五度 (Tritone) 1 → #4 / b5 C → F# 极度不安
7 纯五度 (Perfect 5th) 1 → 5 C → G 最稳定
8 小六度 (Minor 6th) 1 → b6 C → Ab 柔和温暖
9 大六度 (Major 6th) 1 → 6 C → A 明亮开阔
10 小七度 (Minor 7th) 1 → b7 C → Bb 属七·爵士
11 大七度 (Major 7th) 1 → 7 C → B 梦幻·紧张
12 纯八度 (Perfect Octave) 1 → 高音1 C → C' 融合一致

使用方法

想知道 F#m7 的组成音？① 根音 F# = 0；② 小三公式 0-3-7-10：F#+3=A, F#+7=C#, F#+10=E；③ 结果：F# A C# E。
